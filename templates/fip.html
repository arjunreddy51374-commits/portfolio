IMPLEMENTATION BOUNDARY
What this build covers

      
Implemented: entity/source registries, sourced aliases and relationships, a versioned metric catalogue, framework metadata, Manual/Automatic/Hybrid ingestion jobs, approved HTTPS CSV/JSON connectors, persistent global/source/job settings, scheduled retrieval worker, job retries and cancellation, idempotent evidence capture, reviewer-gated validation and publication, correction history, audit lineage, governed period/unit/FX standardization, calculation lineage, immutable data-release snapshots, Excel/CSV/Power BI JSON delivery, and release/NFR registers.

      
Still outside this build: PDF/document extraction, external identity resolution, a native Power BI report package, individual user accounts and SSO, hosted PostgreSQL/object storage, multi-instance scheduler deployment, production monitoring/backup/recovery, measured performance/security assurance, and the deferred forecast/AI/valuation/commercial modules.

07 / ABOUT THIS PROJECT

Transparent research, not a clinical product.

This interactive dashboard compares four classical classifiers on the scikit-learn bundled copy of the Wisconsin Diagnostic Breast Cancer dataset. A stratified 80/20 split is held out for final metrics. Five-fold cross-validation runs only on the training partition. Results describe this dataset and protocol only; they do not establish performance on other populations or clinical settings.

Dataset verified: {{ evaluation.dataset.samples if evaluation else '569' }} records · {{ evaluation.dataset.features if evaluation else '30' }} numerical features · {{ evaluation.dataset.classes.malignant if evaluation else '212' }} malignant · {{ evaluation.dataset.classes.benign if evaluation else '357' }} benign. {% if image_model_ready %}An optional mammography classifier is loaded; it has no clinical validation and does not support X-ray or ultrasound.{% else %}No image classifier is currently loaded.{% endif %} Prediction history and patient record storage are not implemented.
